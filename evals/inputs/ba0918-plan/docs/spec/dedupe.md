# dedupe 仕様

行の重複を取り除く CLI。

## 用語

- **行**：LF（`\n`）で区切られた文字列。CRLF の CR は行の内容の一部として扱う
- **重複**：バイト単位で完全に一致する行。空白や大文字小文字の違いは別の行

## 入力

引数は 0 個か 1 個で、ファイルのパスを取る。
引数が無ければ標準入力から読む。
入力が改行で終わっていなくても、最後の行は行として扱う。

## 重複の定義と残し方

ファイル全体から同じ行を探し、最初の出現だけを残す。
出力の順序は入力の順序を保つ。

成功条件：`a\nb\na\n` を与えると `a\nb\n` が出る。
反例：`a\nb\na\n` に対して `b\na\n`（最後の出現を残す）は誤り。

## 出力

標準出力に書く。各行の後に LF を 1 つ付ける。

## 終了コード

成功は 0。引数のファイルが開けないときは標準エラーに理由を書いて 1。

## 作らない物

- 入力ファイルの書き換え（in-place）
- 複数ファイルの同時処理
- 空白や大文字小文字の正規化

## 却下した案

- 隣接する行だけを比べる `uniq` 方式。離れた重複を取れない

## 未決定

- 無し

## 委任

- エラーメッセージの文言。どの文言でも動作は変わらない
